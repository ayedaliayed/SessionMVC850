كيفية تعديل بيانات موظف — خطوة بخطوة

SessionMVC850 · ASP.NET Core MVC · الدليل بالعربية

قبل أن تبدأ تأكد من بناء المشروع وتشغيله، ومن توفر قاعدة بيانات SQL Server باسم Session850، ومن وجود موظف واحد على الأقل في جدول Employees.

الخطوات

  1. تشغيل التطبيق

    افتح المشروع في Visual Studio واضغط F5، أو نفّذ الأمر التالي في Terminal داخل مجلد المشروع:

    dotnet run

    يبدأ التطبيق على العنوان http://localhost:5090.

  2. فتح قائمة الموظفين

    في المتصفح، انتقل إلى:

    http://localhost:5090/Employee

    هذه هي صفحة Index الخاصة بالموظفين، وتُظهر جميع الموظفين في جدول.

  3. الضغط على رابط التعديل (Edit)

    ابحث عن الموظف الذي تريد تعديله واضغط Edit في صفه. يفتح المتصفح الرابط:

    http://localhost:5090/Employee/Edit/{id}

    مثال: الموظف رقم 3 يفتح الرابط /Employee/Edit/3.

  4. التحقق من البيانات المعبأة مسبقًا

    يحتوي نموذج التعديل على القيم الحالية للموظف، وتُضبط قائمة الأقسام المنسدلة تلقائيًا على قسم الموظف الحالي.

  5. تغيير الحقول المطلوبة
    الحقلما يجب فعله
    الاسم (Name)اكتب اسم الموظف الجديد.
    العمر (Age)اكتب العمر الجديد (أرقام فقط).
    الصورة (Image)اكتب مسار الصورة أو اسم الملف (اختياري).
    الهاتف (Phone)اكتب رقم الهاتف الجديد.
    القسم (Department)اختر القسم من القائمة المنسدلة.
    مهم يجب ألا يكون حقل الاسم فارغًا. إذا كان فارغًا، يُعرض النموذج مرة أخرى ولا يتم حفظ أي شيء.
  6. الضغط على «حفظ التغييرات» (Save Changes)

    يُرسل النموذج إلى POST /Employee/SaveEdit. يتم تحديث سجل الموظف في قاعدة البيانات، ثم تتم إعادة توجيهك إلى قائمة الموظفين.

  7. التحقق من النتيجة

    تظهر قائمة الموظفين مرة أخرى. ابحث عن الموظف وتأكد من ظهور القيم الجديدة في الجدول.

    نجاح إذا رأيت القيم المحدثة في القائمة، فقد تم حفظ التعديل بنجاح.
  8. اختياري: إلغاء (Cancel)

    اضغط Cancel للعودة إلى القائمة دون حفظ أي تغييرات.

كيفية عرض قائمة الأقسام للاختيار منها — خطوة بخطوة

في صفحة التعديل، يكون حقل القسم قائمة منسدلة (<select>)، وتأتي عناصرها من جدول Departments في قاعدة البيانات. وإليك كيفية بنائها بالتفصيل:

  1. المتحكم: تحميل جميع الأقسام

    داخل EmployeeController.Edit، وبعد تحميل الموظف، أحضر كل الأقسام وخزّن القائمة في ViewBag.Departments:

    public IActionResult Edit(int id)
{
    var employee = EmployeeBL.GetById(id);
    if (employee == null)
    {
        return NotFound();
    }

    ViewBag.Departments = DepartmentBL.GetAll();
    return View(employee);
}
  2. الخدمة: قراءة الأقسام من قاعدة البيانات

    تطلب DepartmentBL.GetAll() من Entity Framework جميع الصفوف في جدول Departments:

    public List<Department> GetAll()
{
    return CompanyContext.Departments.ToList();
}
  3. العرض: إنشاء عنصر القائمة المنسدلة

    في Views/Employee/Edit.cshtml تكون القائمة عنصر HTML عاديًا <select>. ويجب أن يكون الاسم name مساويًا لـ DeptId حتى ترتبط القيمة المختارة بخاصية Employee.DeptId:

    <div class="mb-3">
    <label for="DeptId">Department</label>
    <select id="DeptId" name="DeptId" class="form-control">
        ...
    </select>
</div>
  4. العرض: توليد خيار option لكل قسم

    كرّر على القائمة الموجودة في ViewBag.Departments واطبع عنصر <option> لكل قسم، حيث تكون القيمة هي Id والاسم الظاهر هو Name:

    @foreach (var department in (IEnumerable<Department>)ViewBag.Departments)
{
    <option value="@department.Id">@department.Name</option>
}
  5. العرض: تحديد قسم الموظف الحالي مسبقًا

    قارن رقم كل قسم مع Model.DeptId. وعند التطابق أضف الخاصية selected ليظهر هذا القسم مختارًا عند فتح الصفحة:

    @foreach (var department in (IEnumerable<Department>)ViewBag.Departments)
{
    if (department.Id == Model.DeptId)
    {
        <option value="@department.Id" selected>@department.Name</option>
    }
    else
    {
        <option value="@department.Id">@department.Name</option>
    }
}
  6. الإرسال: إرسال رقم القسم المختار إلى الخادم

    عند إرسال النموذج إلى /Employee/SaveEdit، يرسل المتصفح قيمة الخيار المختار باسم DeptId، ويضعها MVC في employee.DeptId.

  7. الحفظ: تخزين القسم الجديد

    تقوم EmployeeBL.Update بنسخ القيمة القادمة من النموذج وحفظها في صف الموظف:

    existing.DeptId = employee.DeptId;
CompanyContext.SaveChanges();
النتيجة تعرض القائمة جميع الأقسام بأسمائها، ويكون قسم الموظف الحالي محددًا مسبقًا، ويُحفظ القسم الذي تختاره مع الموظف.
إذا كانت القائمة المنسدلة فارغة لا توجد صفوف في جدول Departments. أضف قسمًا من صفحات الأقسام أولًا، ثم أعد تحميل صفحة التعديل.
أيضًا عند أخطاء التحقق يعيد SaveEdit تحميل الأقسام قبل عرض النموذج، لذا تبقى القائمة تعمل عند وجود حقل غير صالح: 
ViewBag.Departments = DepartmentBL.GetAll();
return View("Edit", employee);

ماذا يحدث في الخلفية

  1. يرسل المتصفح الطلب GET /Employee/Edit/{id}.
  2. يقوم EmployeeController.Edit بتحميل الموظف عبر EmployeeBL.GetById ويضع الأقسام في ViewBag.Departments.
  3. يعرض ملف Views/Employee/Edit.cshtml النموذج بالقيم الحالية.
  4. عند الضغط على Save Changes يرسل المتصفح الطلب POST /Employee/SaveEdit.
  5. يستدعي EmployeeController.SaveEdit الدالة EmployeeBL.Update التي تنسخ القيم الجديدة إلى صف قاعدة البيانات وتستدعي SaveChanges().
  6. يعيد المتحكم RedirectToAction("Index")، فتظهر القائمة مرة أخرى.

ملفات المشروع المستخدمة

الملفالغرض
Controllers/EmployeeController.cs يحتوي على إجراءي Edit (GET) و SaveEdit (POST).
Services/EmployeeBL.cs يحتوي على GetById (تحميل موظف واحد) و Update (حفظ التغييرات).
Views/Employee/Edit.cshtml نموذج التعديل مع الحقول وقائمة الأقسام المنسدلة.
Views/Employee/Index.cshtml صفحة القائمة التي تحتوي على رابط Edit.

حل المشكلات

المشكلةالحل
خطأ 404 — الصفحة غير موجودة أوقف التطبيق ثم أعد بناءه وشغّله مرة أخرى. تأكد من وجود إجراء Edit داخل EmployeeController.
قائمة الأقسام فارغة أضف قسمًا واحدًا على الأقل أولًا من صفحات الأقسام.
NullReferenceException في قائمة الموظفين يجب أن يمرر إجراء القائمة الموظفين إلى العرض: return View(EmployeeBL.GetAll());
لا يتم حفظ التغييرات تأكد أن حقل الاسم ليس فارغًا وأن SaveChanges() تُستدعى داخل EmployeeBL.Update.
